# TestApplet 需求规格说明书

> 本文档描述 TestApplet 的完整功能需求，供 AppletTestPilot Agent 在测试规划时参考。

---

## 1. 系统概述

TestApplet 是一个**本地离线**微信小程序商城。所有业务数据存储在 `wx.Storage` 中，不依赖任何后端服务或云函数。

### 1.1 用户角色

| 角色 | 说明 |
|------|------|
| 商家 | 唯一的经营者，可创建账户、上传产品、管理库存 |
| 访客 | 浏览商品、加入购物车、收藏、发表评论的消费者 |

> 注：本小程序为单商家模式，同一时刻最多存在一个商家账户。

### 1.2 核心业务流程

```
创建商家 → 上传产品 → 浏览商品 → 商品详情 → 加入购物车 → 管理购物车
                ↓                        ↓
            编辑/删除产品              收藏/评论
```

## 2. 功能需求

### FR-01：商家账户管理

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-01.1 | 用户可从首页或"我的"页面进入商家创建页 | P0 |
| FR-01.2 | 创建页包含 3 个字段：商家名称（必填）、手机号（选填，11位数字）、简介（选填，200字内） | P0 |
| FR-01.3 | 商家名称为空时保存，toast "请输入商家名称" | P0 |
| FR-01.4 | 手机号非空但不满足11位数字时，toast "手机号需为11位数字" | P1 |
| FR-01.5 | 保存成功后，toast "已保存"，300ms 后自动返回上一页 | P0 |
| FR-01.6 | 若已存在商家，创建页自动预填已有信息（编辑模式） | P1 |
| FR-01.7 | 无商家时，首页显示"创建商家"和"去创建商家"两个入口按钮 | P0 |
| FR-01.8 | 有商家时，首页按钮变为"上传产品" | P0 |

| FR-02.6 | 带 `?id=` 参数进入时，自动预填已有产品信息（编辑模式），标题变为"编辑产品" | P1 |
